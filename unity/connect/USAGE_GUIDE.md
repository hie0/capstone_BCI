# 🎮 BCI-유니티 쉬운 사용 설명서 & 투컴(원격) 세팅 가이드

> **"너무 복잡한 이론 빼고, 어떻게 켜고 게임하는지만 쉽게 알려줘!"**  
> 딱 3분 만에 읽고 바로 플레이할 수 있게 정리했습니다.

---

## 💡 이게 도대체 뭔가요? (초간단 3줄 요약)

1. **파이썬(뇌파 서버)**: 뇌파 장비(Explore)에서 신호를 받아서, *"이 사람이 지금 왼손 생각 중인지, 오른손 생각 중인지"* 0.25초마다 확률을 계산합니다.
2. **유니티(게임 화면)**: 파이썬이 보내주는 *"왼쪽 80%, 오른쪽 20%"* 숫자를 받아서 카드를 스와이프하는 게임을 화면에 띄웁니다.
3. 둘 사이는 **인터넷 통신선(TCP 소켓 5000번)**으로 연결되어 있습니다.

---

## 🖥️🖥️ 투컴(2-PC)으로 원격 조종해도 되나요?

**네! 완전 가능하며, 오히려 캡스톤 발표/실험에서는 "투컴 세팅"이 정석이자 가장 추천하는 방식입니다!**

* **왜 투컴이 더 좋나요?**
  * **피험자(게이머)**: 모니터에 게임 화면만 깔끔하게 보면서 뇌파에 집중할 수 있습니다.
  * **조작자(나/연구원)**: 노트북이나 다른 컴에서 파이썬 터미널을 보며 블루투스 연결 상태, 전극 신호 품질, 실시간 확률 로그를 감시할 수 있습니다.

```
[컴퓨터 A (조작자 노트북)]                              [컴퓨터 B (피험자 게임용 PC)]
Explore 뇌파 장비 연결 + 파이썬 서버          -------->       유니티 게임 화면 (카드가 움직임!)
(ip: 192.168.0.15 같은 공유기 IP)           Wi-Fi/LAN           (BCIClient에 A컴 IP 적어주면 끝)
```

### 🛠️ 투컴 세팅 초간단 3단계 (딱 1분 컷)

두 컴퓨터가 **같은 공유기(와이파이 또는 랜선)**에 연결되어 있어야 합니다.

#### 1단계: [A컴 - 파이썬 쪽] A컴퓨터의 IP 주소 확인하기
* A컴퓨터에서 `cmd`나 `터미널`을 열고 `ipconfig` 입력 후 엔터.
* **IPv4 주소**를 확인합니다 (예: `192.168.0.15` 또는 `172.30.1.25`).
* 평소처럼 [start_mock.bat](start_mock.bat) (가상 뇌파) 또는 [start_server.bat](start_server.bat) (실제 장비)를 실행합니다.
  *(윈도우 방화벽 팝업이 뜨면 **"액세스 허용"** 클릭!)*

#### 2단계: [B컴 - 유니티 쪽] A컴 IP 주소 적어주기
* B컴퓨터에서 Unity 프로젝트를 엽니다.
* 화면 좌측 계층구조(Hierarchy) 창에서 **`Bootstrap`** 오브젝트를 클릭합니다.
* 우측 Inspector 창의 **`BCI Client`** 항목을 봅니다:
  * **Host**: 기존 `127.0.0.1` 대신 **A컴퓨터의 IP (예: `192.168.0.15`)**를 적어줍니다.
  * **Port**: `5000` 그대로 둡니다.

#### 3단계: 유니티 플레이!
* Unity 상단 ▶ **Play** 버튼을 누르면 끝!
* A컴퓨터 터미널에 `[+] Unity Connected from 192.168.0.xx` 가 뜨면서 실시간으로 연동됩니다.

## 📦 유니티가 안 깔려 있는 컴퓨터에서도 되나요? (실행 파일 .exe)

**네! B컴퓨터에 유니티가 아예 안 깔려 있어도 100% 가능합니다!**  
유니티가 설치된 컴에서 게임을 **실행 파일(`.exe`)**로 한 번만 뽑아내면, 다른 컴퓨터에서는 그냥 일반 PC 게임처럼 더블 클릭만으로 켜집니다.

### 1. 유니티 컴에서 실행 파일(.exe) 만들기 (딱 1분)
1. 유니티 상단 메뉴에서 `File` → `Build Settings...` 클릭
2. 플랫폼이 `PC, Mac & Linux Standalone` (기본값)인지 확인
3. 우측 하단 **`Build`** 버튼 클릭 → 저장할 폴더 선택 (예: 바탕화면에 `ShelterMind_Game` 새 폴더 만들기)
4. 빌드가 끝나면 `ShelterMind.exe` 파일이 들어있는 게임 폴더가 완성됩니다!

### 2. 유니티 없는 컴(B컴)으로 폴더 복사하기
* 완성된 `ShelterMind_Game` 폴더 전체를 **USB나 압축파일(ZIP)**로 B컴퓨터에 옮깁니다.
* **B컴퓨터에는 유니티가 전혀 없어도 `ShelterMind.exe`만 더블 클릭하면 게임이 바로 뜹니다!**

### 3. 유니티 에디터 없이 A컴 IP 연결하기 (메모장으로 3초 컷)
게임 폴더 안에 있는 **`bci_config.json`** 파일을 **메모장**으로 열어서, A컴퓨터 IP만 적고 저장하면 끝납니다:
```json
{
  "host": "192.168.0.15",
  "port": 5000
}
```
*(원컴에서 할 때는 기본값 `"127.0.0.1"` 그대로 두면 됩니다)*

## 💻 컴퓨터 1대로 혼자 할 때 (원컴 세팅)

컴퓨터 1대에서 다 할 때는 IP를 바꿀 필요도 없습니다.

1. `unity/connect` 폴더에서 **[start_mock.bat](start_mock.bat)** 더블 클릭!
   *(장비 없이도 실제 머신러닝 AI 모델로 가상 뇌파를 쏩니다)*
2. Unity 에디터 상단 ▶ **Play** 클릭!
3. 끝! 카드가 뇌파 확률에 따라 실시간으로 좌/우로 기울어집니다.

## 🎯 게임할 때 어떻게 플레이하나요?

게임이 시작되면 다음과 같이 세련된 하이테크 프로토콜로 진행됩니다:

1. **타이틀 화면 (Subject & Model 선택)**:
   * 피험자 ID(예: `S01`)와 디코더 모델(Base / Fine-tuned / Mock)을 인게임 드롭다운에서 선택합니다.
   * **[RUN PRE-GAME BCI CHECK (6 TRIALS)]** 또는 **[ENTER COMMAND CODES]**를 클릭합니다.

2. **Pre-Game BCI Check (칼리브레이션 단계 - 게임 온라인 프로토콜 유사 UI)**:
   * 본 게임의 CUE 화살표 및 밸런스 게이지와 동일한 레이아웃으로 좌 3회, 우 3회(총 6회, 약 1분) 간소화 검사를 수행합니다.
   * 검사 완료 후 **Fine-tuning Safety Gate(기준치 OOF AUC >= 0.55)** 안전망을 검증하고 당일 베이스라인을 확정합니다.

3. **Step 1: 카드 읽기 (3초)**  
   * 화면에 좀비 생존 스토리와 선택지가 나옵니다.  
   * *(이때는 뇌파가 작동하지 않고 잠겨 있습니다. 답답하면 `스페이스바` 누르면 바로 스킵됩니다!)*

4. **Step 2: MI Focus Mode (최대 5초)**  
   * 주변 HUD가 어둡게(Dim) 전환되어 시각 집중을 극대화합니다.
   * 화면 중앙 CUE와 하단 밸런스 게이지가 반응하며, **Python 서버가 최종 판정한 Trigger("LEFT"/"RIGHT")가 단일 진실 공급원**으로 즉시 카드를 스와이프합니다.
   * *(화면 좌우의 오실로스코프 그래프는 시각 자극 방지를 위해 기본 숨김 처리되어 있으며, 원할 경우 `F1` 키로 토글할 수 있습니다.)*

5. **Step 3: 카드 스와이프 및 피드백**  
   * 벙커 4대 자원(물자, 탄약, 방호도, 사기) 변화와 생존 스토리를 확인합니다.

6. **Day 5 정기 휴식 (Rest Phase)**:
   * 20턴 이후의 인지 피로 누적을 방지하기 위해 매 5턴(Day 5, 10, 15, 20, 25)마다 15초 정기 휴식 모달이 열립니다.
   * **희영안 채택 (Parameter Lock)**: 세션 중 임의로 파라미터를 변경하지 않고 통제된 베이스라인을 유지하며, 피험자가 준비되면 언제든지 `스페이스바` 또는 `[RESUME]` 버튼으로 즉시 게임을 재개할 수 있습니다!

### 🎮 키보드로 강제 조작하고 싶을 때
* 서버가 꺼져 있거나 테스트할 때는 키보드로도 됩니다:
  * `←` 또는 `A` 키 (꾹 누름): 왼손 확률 상승
  * `→` 또는 `D` 키 (꾹 누름): 오른손 확률 상승
  * `Space` 키: 카드 읽기 대기시간 즉시 스킵

## 📁 배치 파일(.bat) 4총사 용도 정리

폴더에 있는 `.bat` 파일들은 마우스 더블 클릭으로 바로 쓰는 실행기입니다:

| 파일명 | 언제 쓰나요? |
| :--- | :--- |
| **`start_mock.bat`** | **[가장 많이 씀 ⭐]** Explore 장비 없을 때 실제 AI 모델로 테스트할 때 |
| **`start_server.bat`** | **[실제 뇌파 캡 착용 시]** 블루투스로 `Explore_DABP` 연결해서 플레이할 때 |
| **`start_dummy.bat`** | 파이썬 환경이 없는 다른 친구 컴에서 유니티 UI만 가볍게 돌려볼 때 |
| **`test_client.bat`** | 유니티 켜기 전에 "서버가 패킷 잘 쏘고 있나?" 확인할 때 |

## ❓ 자주 하는 질문 (트러블슈팅)

### Q. 유니티를 켰는데 카드가 안 움직여요!
1. `start_mock.bat` 창이 켜져 있는지 확인하세요.
2. 유니티 상단 헤더 글씨가 `🟢 BCI ONLINE`인지 확인하세요.
3. 유니티 콘솔창에 빨간 에러가 없는지 보세요.

### Q. 포트 5000번 에러(Address already in use)가 떠요!
* 이전 파이썬 창이 백그라운드에 남아있는 것입니다.
* 파이썬 까만 창을 다 닫거나, 컴퓨터를 재부팅하면 바로 해결됩니다.

### Q. 투컴 연결이 안 돼요!
1. A컴과 B컴이 **같은 공유기(Wi-Fi)**인지 확인하세요 (핸드폰 핫스팟으로 두 컴을 연결해도 아주 잘 됩니다!).
2. A컴에서 서버를 처음 켤 때 윈도우 방화벽 창이 뜨면 반드시 **"액세스 허용"**을 눌러야 다른 컴퓨터의 접속을 허락합니다.
3. B컴 유니티의 `Host`에 A컴 IP를 오타 없이 잘 적었는지 확인하세요.

### Q. 유니티가 안 깔려있는 노트북에서 플레이하려면?
* 유니티가 설치된 컴에서 `File` → `Build Settings...` → `Build` 눌러서 `.exe` 폴더를 만들어 B컴퓨터에 옮기세요.
* B컴퓨터에서는 유니티를 깔 필요 없이 `ShelterMind.exe`를 더블 클릭하기만 하면 바로 켜집니다.
* IP 설정은 게임 폴더 내 `bci_config.json` 파일을 메모장으로 열어서 A컴 IP만 적어주면 끝납니다.

## 🚀 [실전 요약] 실전 시나리오 2가지 스텝-바이-스텝

현재 환경에 맞는 상황을 골라서 그대로 따라 하시면 됩니다!

---

### 🟢 [상황 1] 유니티가 아예 안 깔린 컴퓨터 1대만 쓸 때 (실험 컴퓨터 단독)
> **"실험 컴퓨터에 파이썬/Conda만 있고 유니티 프로그램은 안 깔려 있어요!"**  
> 💡 유니티 설치할 필요 없이, **게임 실행 파일(`ShelterMind.exe`) 폴더**만 복사해 두면 바로 됩니다.

#### 1. 터미널(VS Code / CMD)에서 서버 켜기
```bash
conda activate bci
cd "c:\Users\hsshi\OneDrive\문서\jinny\capstone_BCI"

# [장비 없이 AI 가상 뇌파로 테스트할 때]
python bci_tcp_server.py --mock --subject oyj

# [실제 Explore 블루투스 뇌파 장비 연결할 때]
python bci_tcp_server.py --device Explore_DABP --subject oyj
```
*(터미널에 `[*] [BCI TCP Server] Listening on 0.0.0.0:5000`가 뜨면 준비 완료!)*

#### 2. 게임 켜기
* 복사해 둔 폴더에서 **`ShelterMind.exe`**를 마우스로 **더블 클릭**!  
*(같은 컴퓨터이므로 IP 변경 없이 자동으로 `127.0.0.1`로 즉시 연결되어 카드가 뜹니다)*

#### 3. 게임 끝내기
* 게임 창 닫기 (`Alt + F4` 또는 창 닫기 X 버튼)
* 터미널에서 `Ctrl + C` 로 서버 종료

---

### 🔵 [상황 2] 유니티 있는 노트북 + 실험 컴퓨터 2대로 진행할 때 (투컴 원격)
> **"노트북에는 유니티가 깔려 있고, 뇌파 장비는 실험 컴퓨터에 연결해서 원격으로 할 거예요!"**  
> 💡 두 컴퓨터를 **같은 와이파이(또는 핸드폰 핫스팟)**에 연결하세요.

#### 1. [실험 컴퓨터] 뇌파 서버 켜기
1. 터미널에서 `ipconfig` 치고 **IPv4 주소**(예: `192.168.0.15`)를 적어둡니다.
2. 서버 실행:
   ```bash
   conda activate bci
   cd "c:\Users\hsshi\OneDrive\문서\jinny\capstone_BCI"

   # [실제 장비 연결 시]
   python bci_tcp_server.py --device Explore_DABP --subject oyj

   # [장비 없이 가상 뇌파 시]
   python bci_tcp_server.py --mock --subject oyj
   ```
   *(윈도우 방화벽 팝업이 뜨면 반드시 **"액세스 허용"** 클릭!)*

#### 2. [내 노트북] 유니티 게임 켜기
1. 노트북에서 Unity 에디터로 프로젝트를 엽니다.
2. 화면 왼쪽(Hierarchy)에서 **`Bootstrap`** 오브젝트 클릭.
3. 오른쪽(Inspector) 창의 **`BCI Client`** 항목을 봅니다:
   * **Host**: `127.0.0.1` 대신 **실험 컴퓨터의 IP (예: `192.168.0.15`)**를 적어줍니다.
   * **Port**: `5000` 그대로 둡니다.
4. 상단 **▶ (Play)** 버튼 클릭!
   *(실험 컴퓨터 터미널에 `[+] Unity Connected`가 뜨면서 두 컴퓨터가 무선으로 실시간 연동됩니다)*

#### 3. 게임 끝내기
* 노트북: 유니티 **▶ (Play)** 다시 눌러 정지
* 실험 컴퓨터: 터미널에서 `Ctrl + C` 로 서버 종료

> 💡 **꿀팁**: 내 노트북에서 한 번만 `File` → `Build Settings` → `Build` 눌러서 `ShelterMind.exe` 폴더를 만들어 실험 컴퓨터에 USB로 넘겨주면, 다음부터는 노트북 없이도 **[상황 1]**처럼 실험 컴퓨터 1대만으로 바로 게임을 켤 수 있습니다!
